## Task 1 — Calculator

**Repository:** `calculator`

A fully functional browser-based calculator built with **HTML, CSS, and JavaScript** — no frameworks or external dependencies.

### Features
- Standard arithmetic: addition, subtraction, multiplication, division
- Percentage operator
- Chained operations without pressing `=` each time
- Calculation history (last 10 results) — tap any entry to reuse the result
- Backspace to delete the last digit
- Division-by-zero error handling
- Full keyboard support (`0–9`, `+ - * /`, `%`, `Enter`, `Backspace`, `Escape`)
- Responsive card layout (max-width 420 px)

### Tech Stack
`HTML` `CSS (Grid)` `Vanilla JavaScript`

### How to Run
```
Open index.html in any modern browser — no build step required.
```

## Task 3 — A Basic To-Do Webapp

**Repository:** `a-basic-to-do-webapp`

A clean task management web app that lets users add, complete, edit, and delete daily tasks, with separate **Pending** and **Completed** sections.

### Features
- Add new tasks to the list
- Mark tasks as complete — moves them to the Completed section automatically
- Edit existing tasks inline
- Delete tasks from either list
- Pending and Completed tasks displayed in separate sections
- Date and time recorded when a task is added and completed
- Persistent state across page refreshes (localStorage)

### Tech Stack
`HTML` `CSS` `Vanilla JavaScript` `localStorage`

### How to Run
```
Open index.html in any modern browser — no build step required.
```
