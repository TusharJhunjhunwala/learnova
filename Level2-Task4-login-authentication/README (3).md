## 📌 Project Overview

A clean, fully functional Login Authentication System built with **HTML, CSS, and JavaScript**. The app allows users to register a new account, log in with their credentials, and access a secured dashboard page — all in a single-page application with smooth transitions.

---

## 🚀 Features

- 📝 **User Registration** — name, email, password with confirm password
- 🔐 **User Login** — email & password authentication
- 🛡️ **Secured Dashboard** — accessible only after successful login
- ✅ **Input Validation** — all fields validated before submission
- 🔒 **Password Strength Indicator** — live strength meter while typing
- 👁️ **Show/Hide Password** — toggle password visibility
- ⚠️ **Error Messages** — clear inline field-level error messages
- 🚪 **Logout** — returns user to the login screen
- 💾 **Persistent Users** — registered users saved in localStorage

## ▶️ How to Run

1. Clone or download the repository
2. Open `index.html` in any modern web browser
3. No installations or servers required

---

## 💡 How to Use

1. Click **"Register"** tab to create a new account
2. Fill in name, email, and password — watch the strength meter
3. Click **"Create account"** to register
4. Switch to **"Sign in"** tab and log in with your credentials
5. You'll land on the secured **Dashboard** with your account info
6. Click **"Sign out"** to log out

---

## 🔒 Security Features Implemented

- Email format validation using regex
- Password minimum length enforcement (6 characters)
- Password confirmation match check
- Duplicate email registration prevention
- Field-level error messages for all invalid inputs
