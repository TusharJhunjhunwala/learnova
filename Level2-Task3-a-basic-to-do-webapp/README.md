## 📌 Project Overview

A clean, fully functional To-Do Web Application built with **HTML, CSS, and JavaScript**. The app allows users to manage their daily tasks efficiently — adding, editing, completing, and deleting tasks, with automatic separation of Pending and Completed tasks.

---

## 🚀 Features

- ✅ Add new tasks via input field or pressing **Enter**
- 📋 Tasks separated into **Pending Tasks** and **Completed Tasks** sections
- ✔️ Mark tasks as complete — they move to the Completed section automatically
- ✏️ Inline editing of pending tasks on hover
- 🗑️ Delete tasks from either section
- 🕐 Timestamp on every task — shows when it was **added** and when it was **completed**
- 🔢 Live task counters for both sections
- 📱 Responsive layout that works on desktop and mobile

---

## 💡 How to Use

1. Type a task in the input field at the top.
2. Press **Enter** or click **Add task** to add it to the Pending list.
3. Click the **circle** on the left of a task to mark it complete.
4. Hover over a pending task to reveal **Edit** and **Delete** icons.
5. Completed tasks display a completion timestamp and can be deleted.
